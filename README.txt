# РОЙО — сайт свечи La Automne

## Что внутри
- index.html — сайт в бежево-коричневой палитре, с баннером РОЙО, овальными ссылками и скруглёнными карточками.
- Фотографии баннера и свечи встроены прямо в index.html — отдельные файлы изображений не нужны.
- package.json и server.js — прежняя серверная часть для Node.js и Telegram-заказов.

## Запуск
1. Установи Node.js 18 или новее.
2. В этой папке выполни `npm install`.
3. Создай файл `.env` с переменными:
   BOT_TOKEN=токен_твоего_бота
   CHAT_ID=твой_telegram_id
4. Запусти `npm start`.

Важно: текущая витрина оформляет заказ через сообщество ВКонтакте по инструкции на странице. Серверный маршрут Telegram `/api/order` сохранён в проекте, но кнопка витрины сейчас ведёт в сообщество ВКонтакте. Токен бота не вставляй в HTML.
